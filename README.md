# 🧾 Чек-сканер

Программа принимает фото чека, распознаёт текст (OCR), находит **номер смены** и
**сумму чека в рублях**, и дописывает запись в Excel-файл `receipts.xlsx`.
После сохранения можно загрузить следующий чек — записи накапливаются в таблице.

## Структура

- `app.py` — приложение Streamlit
- `requirements.txt` — зависимости Python
- `tesseract-env/` — предустановленный Tesseract OCR 5.5.3 со всеми языками (включая русский)
- `micromamba.exe` — утилита, которой устанавливался Tesseract (нужна только для обновления)
- `receipts.xlsx` — создаётся автоматически рядом с `app.py`
- `test_ocr.py` — интеграционный тест OCR (`python receipt_parser\test_ocr.py`)

## Установка

### 1. Установить Python-зависимости

```cmd
cd receipt_parser
pip install -r requirements.txt
```

### 2. Tesseract OCR — уже установлен

Tesseract OCR 5.5.3 (с русским языком) уже предустановлен в папку
`tesseract-env/` внутри проекта. Никаких дополнительных установок не требуется.

Папка `tesseract-env/` не хранится в Git (весит ~220 МБ). Если её нет — например,
после клонирования репозитория на другом компьютере — установите Tesseract так:

1. Скачайте `micromamba.exe` (один файл, ~12 МБ):
   https://github.com/mamba-org/micromamba-releases/releases/latest/download/micromamba-win-64.exe
   и положите его в папку проекта.
2. Выполните в папке проекта:

```cmd
micromamba.exe create -y -p tesseract-env -c conda-forge tesseract
```

В поставку входят все языки, включая русский (`rus`).

Приложение автоматически находит Tesseract в `tesseract-env`; при его отсутствии
используется Tesseract из системного PATH (тогда установите его вручную с
официального установщика UB-Mannheim и добавьте русский язык).

## Запуск

```cmd
cd C:\Users\funtusov\Python projects\receipt_parser
python -m streamlit run app.py
```

В браузере откроется страница приложения (обычно http://localhost:8501).

## Как пользоваться

1. Загрузите фото чека (JPG/PNG).
2. Программа распознает текст и автоматически подставит номер смены и сумму.
3. Проверьте/исправьте значения в полях и нажмите **«Сохранить в Excel»**.
4. Загрузите следующий чек — запись добавится новой строкой.
5. Готовый файл можно скачать кнопкой **«Скачать Excel-файл»**.
6. Чтобы удалить запись: кликните по нужной строке в таблице «Сохранённые записи»
   (можно выбрать несколько строк с `Ctrl`/`Shift`) и нажмите
   **«🗑 Удалить выбранную строку»**. Порядковые номера пересчитаются автоматически.

## Что ищется на чеке

- Номер смены: слова `СМЕНА`, `СМ`, `СМЕНЫ` + число (например `СМЕНА 123`).
- Сумма: слова `ИТОГ`, `ИТОГО`, `ВСЕГО`, `СУММА`, `ОПЛАТА` + число
  (поддерживаются форматы `1250.50`, `1250,50`, `1 250 руб`).

## Советы по качеству распознавания

- Снимайте чек при хорошем освещении, без бликов и теней.
- Чек в кадре должен занимать большую часть изображения, текст — читаемый.
- Фото делайте строго сверху (без перспективных искажений).
